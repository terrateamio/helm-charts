BACKUPS
-------
The bundled PostgreSQL is for evaluation and small installs. Back it up before
any chart upgrade:

  kubectl exec -n {{ template "application.namespace" . }} deploy/{{ template "application.name" . }}-{{ .Values.db.name }} -- \
    pg_dumpall -U {{ .Values.db.config.username }} > terrateam-backup.sql

{{ if .Values.db.pvc.retain -}}
The PersistentVolumeClaim is annotated helm.sh/resource-policy: keep, so your
data survives `helm uninstall`. Delete it by hand when you really mean to:

  kubectl delete pvc -n {{ template "application.namespace" . }} {{ template "application.name" . }}-{{ .Values.db.pvc.name }}
{{- else }}
WARNING: db.pvc.retain=false, so `helm uninstall` DELETES the PersistentVolumeClaim
and every byte of Terrateam's data with it.
{{- end }}
{{- end }}
